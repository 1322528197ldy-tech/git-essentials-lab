# Exercise 05: Restore and revert

**Mode:** Restore is local practice; the revert result is submitted.

## Situation

There are two different mistakes: an uncommitted debug receipt and an older committed change that bypasses borrowing limits. A later return guide is useful and must remain.

## Start

Run from the launcher:

```text
python3 lab.py start 05
```

Open the workspace path printed by `start`. The workspace starts on `result/ex05` at `lab-v1/ex05/start`. `src/library/LoanReceipt.java` has an unstaged `DEBUG: ` edit. The bad policy is identified by `lab-v1/ex05/bad-policy`; a newer commit adds `docs/return-guide.md`.

## Inspect this exercise

Inside the workspace:

```text
git log --oneline --graph --decorate HEAD lab-v1/ex05/bad-policy
```

Use `git show lab-v1/ex05/bad-policy` to inspect the specific change before undoing it.

## Task

1. Inspect the receipt diff and restore that uncommitted file to its committed content. Confirm that this changes the working tree without adding a commit.
2. Inspect the bad-policy commit and the later return-guide commit. Revert the bad-policy commit while preserving the later history. Keep Git's generated `This reverts commit <hash>.` line in the new commit message, with the actual bad-policy commit ID instead of the placeholder.
3. Inspect the new corrective commit, the return guide, and the application behavior.

## Success conditions

- The receipt again uses `Loan: `, with no `DEBUG: ` edit.
- Both student and faculty borrowing limits return to **2**. The 14-day loan period, nonnegative 100-per-day fee, and case-sensitive search remain unchanged.
- The original bad commit and the later guide remain in history, followed by a revert commit. `docs/return-guide.md` still says to return the book before its due date.

## Check

From the launcher, use the exact workspace path printed at start:

```text
python3 lab.py check 05 --repo "/PATH/TO/YOUR/WORKSPACE"
```

Compare restoring an uncommitted file with reverting a committed change. The submitted result must retain the original starting history; resetting the branch to an older commit would also lose later work.

## Submission

Publish `result/ex05`. The corrective history and preserved guide are submitted. The earlier local restore action itself is not remotely graded.

## Restart

Run `python3 lab.py start 05` again from the launcher to create a fresh workspace. It leaves the old attempt intact.
