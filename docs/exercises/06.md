# Exercise 06: Stash interrupted work

**Mode:** Local-only practice; not remotely graded.

## Situation

You are improving receipts and taking notes when an urgent request arrives: increase the loan period to 21 days. Save the unfinished work, make the urgent change separately, then resume.

## Start

Run from the launcher:

```text
python3 lab.py start 06
```

Open the workspace path printed by `start`. The workspace starts on `result/ex06` at `lab-v1/ex06/start`. `src/library/LoanReceipt.java` has an uncommitted `Borrowed: ` change. `notes/search-ideas.txt` is an untracked note containing `Search should ignore case.`.

## Task

1. Inspect both unfinished items. Save them in a stash, including the untracked note, and confirm that they are no longer in the working tree.
2. Change the loan period to **21 days** and commit that urgent fix without including the receipt or note.
3. Restore the saved work. Verify the receipt change and note before deciding whether to remove the stash entry. Leave the resumed receipt and note uncommitted for inspection.

## Success conditions

- The urgent commit changes the loan period to 21 days without bundling the unfinished receipt or note.
- The working tree again contains the `Borrowed: ` receipt change and the original search note.
- The borrowing limits remain two books each, overdue fees remain nonnegative at 100 per day, and catalog search remains case-sensitive. The note is an idea, not a completed search feature.

## Check

From the launcher, use the exact workspace path printed at start:

```text
python3 lab.py check 06 --repo "/PATH/TO/YOUR/WORKSPACE"
```

Inspect `git status`, the urgent commit, and `git stash list`. The checker can verify current files and behavior but cannot prove that you temporarily stored them in a stash.

## Submission

No remote submission is required. Stash entries and the untracked working-tree state belong to this local workspace.

## Restart

Run `python3 lab.py start 06` again from the launcher to create a fresh workspace. It leaves the old attempt intact.
