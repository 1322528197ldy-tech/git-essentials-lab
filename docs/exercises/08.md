# Exercise 08: Reset and split a commit

**Mode:** Local-only practice; not remotely graded.

## Situation

A private commit mixes a receipt-code change with documentation. Keep all of the content, but separate it into two focused commits.

## Start

Run from the launcher:

```text
python3 lab.py start 08
```

Open the workspace path printed by `start`. The workspace starts on `result/ex08` with one local commit named `mixed changes` after `lab-v1/ex08/start`. It changes `src/library/LoanReceipt.java` and adds `docs/receipt.md`.

## Task

1. Inspect the mixed commit and identify its two file changes.
2. Move the branch back to the starting commit while retaining the changes. Inspect where those changes are now: staging area or working tree.
3. Rebuild the work as two focused commits: one for the receipt code and one for the documentation. Give each a meaningful message.

## Success conditions

- Exactly **two** commits follow the starting tag. Each changes only one of the two intended paths.
- The receipt still uses `Borrowed: `, and the document still confirms the borrowed book title. No content was lost.
- The application retains baseline borrowing and search behavior; the completed working tree is clean.

## Check

From the launcher, use the exact workspace path printed at start:

```text
python3 lab.py check 08 --repo "/PATH/TO/YOUR/WORKSPACE"
```

Explain how your reset mode affected the branch pointer, index, and working tree. The final two commits alone do not demonstrate which reset mode you practiced.

## Submission

No remote submission is required. This exercise is local practice in reorganizing unpublished work.

## Restart

Run `python3 lab.py start 08` again from the launcher to create a fresh workspace. It leaves the old attempt intact.
