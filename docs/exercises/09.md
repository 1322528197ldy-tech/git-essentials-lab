# Exercise 09: Cherry-pick only the required fix

**Mode:** Submitted result.

## Situation

Negative overdue days currently produce a negative fee. Another development line has the fix, but also contains an unfinished reservation prototype and experimental debug notes that must not enter this release.

## Start

Run from the launcher:

```text
python3 lab.py start 09
```

Open the workspace path printed by `start`. The workspace starts on `result/ex09` at `lab-v1/ex09/start`. The donor history is at `lab-v1/ex09/donor`. It contains a reservation commit, the required fee fix, then a debug-notes commit. The donor tag points to the end of that history, not directly to the fix.

## Task

See the [starting commit graph](../GRAPHS.md#exercise-09-one-useful-patch-in-a-longer-history) to distinguish the donor tip from its required middle patch.

1. Inspect the donor log and individual patches to identify the fee-fix commit. Do not assume the donor tip is the desired change.
2. Apply only the required fix to the result branch with cherry-pick.
3. Inspect the resulting patch and confirm that neither unrelated file has entered your branch.

## Success conditions

- The fee is **0** for negative or zero overdue days and **100 per day** for positive overdue days.
- Exactly one new commit follows the start. Neither `src/library/Reservation.java` nor `docs/debug-notes.md` is present. The full donor history is not merged.
- Student and faculty limits remain 2, loans remain 14 days, and search remains case-sensitive.

## Check

From the launcher, use the exact workspace path printed at start:

```text
python3 lab.py check 09 --repo "/PATH/TO/YOUR/WORKSPACE"
```

The starting application intentionally fails the negative-fee behavior check. After selecting the fix, compare the result commit with the donor patch; the new commit can have a different ID.

## Submission

Publish `result/ex09`. No PR is required.
