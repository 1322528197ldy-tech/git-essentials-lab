# Exercise 07: Amend an incomplete commit

**Mode:** Submitted result.

## Situation

Your latest private commit improves the receipt, but its message is unfinished and its documentation was left out. Replace it with one complete commit before publishing.

## Start

Run from the launcher:

```text
python3 lab.py start 07
```

Open the workspace path printed by `start`. The workspace starts on `result/ex07`. Its base is `lab-v1/ex07/start`; local setup adds one commit named `wip receipt` and leaves `docs/receipt.md` untracked. The receipt code already uses `Borrowed: `.

## Inspect this exercise

Inside the workspace:

```text
git log --oneline --graph --decorate HEAD lab-v1/ex07/start
```

Compare the commit ID and count before and after amendment.

Before the first publication, also inspect:

```text
git branch -vv
git ls-remote --heads origin refs/heads/result/ex07
```

An unset tracking branch is useful context but does not prove that a commit was never pushed. If `ls-remote` succeeds with no output, **that exact branch is absent from `origin`**; it does not prove that the commit is absent under every other remote ref. Setup creates this WIP commit locally and does not publish it. If the command fails, treat that as an authentication/network error, not evidence of absence. If a result branch already exists from an earlier attempt, inspect it before publishing this attempt.

## Task

1. Inspect the latest commit and the untracked receipt document. Confirm that this setup commit has not been published by the launcher.
2. Amend the latest commit to include both the receipt code and its documentation. Use the exact message `feat: improve loan receipt`.
3. Inspect the replacement commit and compare the number of commits after the starting tag.

## Success conditions

- Exactly **one** commit follows `lab-v1/ex07/start`, with the message `feat: improve loan receipt`.
- That commit includes the `Borrowed: ` receipt and `docs/receipt.md`, which confirms the borrowed book title.
- The application keeps its baseline borrowing and search behavior, and the working tree is clean.

## Check

From the launcher, use the exact workspace path printed at start:

```text
python3 lab.py check 07 --repo "/PATH/TO/YOUR/WORKSPACE"
```

The old and amended commit IDs should differ. Adding a second commit would not satisfy the one-complete-commit result requested here.

Git normally preserves the original **author** when amending, while recording the person making the amendment as **committer**. Seeing `Lab Setup` as author is expected for this prepared commit; author identity is not a grading condition. You can inspect both with `git log -1 --format=fuller`. If you deliberately want to claim authorship of this private replacement commit, `--reset-author` is an optional `git commit --amend` flag, not a requirement.

## Submission

Publish `result/ex07` after finishing the amendment. This is its first publication; no force push is needed.

## Restart

Run `python3 lab.py start 07` again from the launcher to create a fresh workspace. It leaves the old attempt intact.
