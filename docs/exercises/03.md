# Exercise 03: Fetch and pull

**Mode:** Local-only practice; not remotely graded.

## Situation

A teammate extends the loan period while your local branch still has the original policy. Observe what fetch updates, then bring the new commit into your current branch.

## Start

Run from the launcher:

```text
python3 lab.py start 03
```

The workspace starts on `result/ex03` at `lab-v1/ex03/start`, with a 14-day loan period. Setup creates a local remote named `practice` with a branch also named `practice`. This is a simulated shared repository on your computer; `origin` still points to your GitHub fork.

## Inspect this exercise

Inside the workspace:

```text
git log --oneline --graph --decorate HEAD practice/practice
```

Run this before and after fetching, then after pulling. The remote-tracking ref changes only when your local Git learns about the remote update.

## Task

1. In the workspace, inspect the current branch, its tracking relationship, the current commit, and the loan period.
2. From the launcher, create the simulated teammate update:

   ```text
   python3 lab.py advance 03 --repo "/PATH/TO/YOUR/WORKSPACE"
   ```

3. Return to the workspace. Fetch from `practice`, then compare `practice/practice` with your current branch. Observe that fetching updates the remote-tracking reference without changing the current branch or its 14-day source file.
4. Integrate the update with an explicitly fast-forward-only pull from the `practice` remote's `practice` branch. Inspect the updated policy and graph.

## Success conditions

- The final loan period is **21 days**. Limits remain two books per member, fees remain nonnegative at 100 per day, and search remains case-sensitive.
- The current branch includes the simulated teammate commit. No merge commit is needed because the local branch had no independent new commits.
- You can identify which reference moved after fetch and which moved after pull.

## Check

From the launcher:

```text
python3 lab.py check 03 --repo "/PATH/TO/YOUR/WORKSPACE"
```

The final check verifies behavior. The intermediate observation that fetch did not change your working branch is part of the local exercise, not something the final files can prove.

## Submission

No remote submission is required. `advance` modifies only the local simulated remote; it does not push a teammate commit to GitHub.

## Restart

Run `python3 lab.py start 03` again from the launcher. The new workspace has its own simulated remote, so it does not reuse the advanced state from the old attempt.
